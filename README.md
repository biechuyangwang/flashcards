# 📇 生词训练卡 · Vocabulary Flashcards

配合两套课程教学材料的生词闪卡训练应用：**纯前端、离线可用、手机电脑通用**。

**👉 在线使用：https://biechuyangwang.github.io/flashcards/**

## 功能

- **双课程词库**（2214 条，由教案机器抽取，`build_vocab_db.py` 一键重建）：
  - 对外汉语 1104 词（拼音 · 词性 · 英译，1—6 级，出自 115 课教案）
  - 英语 1110 词（词性 · 中文释义，1—6 级，出自 115 课教案）
- **双向训练**：认忆（看词忆义，自动发音）/ 产出（看释义说词）
- **间隔重复**：不认识 10 分钟 → 模糊 12 小时 → 认识 3 天起间隔倍增；到期词优先出现
- **词表浏览**：按级别/课次筛选，中英文搜索，逐词点读
- **进度管理**：localStorage 持久化，可导出/导入 JSON 备份；错词重刷；学习统计

## 使用

手机或电脑浏览器打开上方链接即可；也可把 `index.html + vocab_db.js` 两个文件拷到本地离线使用（发音用系统内置语音合成）。

## 重建词库

词库源为两套课程教案（`汉字汉语普及/教学材料` 与 `英语普及/教学材料`）。教案更新后运行 `build_vocab_db.py` 重新生成 `vocab_db.js` 并推送即可。
